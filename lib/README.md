# Vendored libraries

Copied from [papyrix-reader](https://github.com/bigbag/papyrix-reader)
(MIT, © Pavel Liashkov, see `PAPYRIX_LICENSE`). Parts of it derive from FreeInk
(MIT, see the `FREEINK_LICENSE` files in each library).

| Library | Contents |
|---|---|
| `EInkDisplay` | SSD1677 / SSD2677 e-ink drivers, Sticky panel probe |
| `BoardSupport` | board profiles, hardware identity, power policy |
| `Logging` | log macros used by the above |
| `SDPowerControl` | SD power gating, extracted from papyrix-reader's SDCardManager |

Local changes are listed in [docs/HARDWARE.md](../docs/HARDWARE.md#changes-to-the-vendored-papyrix-reader-libraries).
